# Empirical Bernstein in smooth Banach spaces 

Implementation of the experiments shown in the paper Empirical Bernstein in smooth Banach spaces. 

## Structure

The repository contains 
- Python scripts, which contain the working code of the experiments. 
- One python notebook, which make use of the scripts to make the plot displayed in the paper. 

## Scripts

**mainci.py** runs the main simulations of the project. 


**distributions.py** contains the implementation of distributions we draw samples from.
**experiments.py** defines the experiments. 
**utils.py** defines auxiliary functions.


## Notebooks

**read_data_ksd.ipynb** makes use of the data generated by the previous files to generate the plot.
